## 📁 Project Directory (As per Internship Guidelines)

1. **HR Analytics Dashboard**
   - **Description:** An extensive Exploratory Data Analysis (EDA) and visualization project focused on uncovering employee attrition trends and performance metrics. Analyzed large-scale datasets (**50,000+ records**) and utilized **Power BI** to build interactive dashboards, achieving 100% data accuracy to streamline strategic HR decision-making.
   - **Repository:** [HR-Analytics-Attrition-Dashboard](https://github.com/mdsalmanfarsi692004-svg/HR-Analytics-Attrition-Dashboard)

2. **FraudGuard AI (Financial Anomaly Detection)**
   - **Description:** A high-performance predictive model engineered to detect fraudulent financial transactions in real-time. Addressed severe class imbalance using the **SMOTE** technique and leveraged **Isolation Forest** & **Logistic Regression**, successfully reducing false-positive alerts by 15% and improving minority class recall by 25%.
   - **Repository:** [Financial-Fraud-Detection-System](https://github.com/mdsalmanfarsi692004-svg/Financial-Fraud-Detection-System)

3. **MediGuard AI (Healthcare Diagnostics)**
   - **Description:** A machine learning-powered healthcare diagnostic tool built to predict disease risks based on complex patient data metrics. Deploys predictive classification algorithms via a `Streamlit` web interface for rapid, real-time medical data assessments.
   - **Repository:** [MediGuard-AI-Multi-Disease-Prediction](https://github.com/mdsalmanfarsi692004-svg/MediGuard-AI-Multi-Disease-Prediction)

4. **WAF Shield (Web Application Firewall Classifier)**
   - **Description:** An intelligent cybersecurity classification model designed to analyze network traffic logs and detect malicious web attacks (such as SQL Injection or XSS). Leverages Python-based ML classifiers to distinguish anomalous request patterns and bolster web application security.
   - **Repository:** [WAF-Shield-AI-Powered-Web-Threat-Detection](https://github.com/mdsalmanfarsi692004-svg/WAF-Shield-AI-Powered-Web-Threat-Detection)
